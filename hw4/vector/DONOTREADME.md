## Версия 1 (глава 17)

Учебный класс `vector` для хранения последовательности чисел типа `double` в динамической памяти.

**Что умел:**
- конструктор `vector(int s)` — выделял память под `s` элементов и инициализировал их нулями;
- деструктор — освобождал память через `delete[]`;
- `size()` — возвращал количество элементов;
- `get(n)` / `set(n, v)` — чтение и запись элемента по индексу.

**Чего не умел:**
- копироваться (копирование по умолчанию приводило к двойному `delete[]`);
- перемещаться;
- инициализироваться списком значений;
- индексироваться через `[]`;
- создаваться без аргументов.

**Внутреннее устройство:** два члена — `int sz` и `double* elem`.

## Версия 2 (глава 18)

Тот же класс для `double`, но с корректной семантикой копирования и перемещения и с доступом через `[]`.

**Что добавилось:**

| Что | Зачем |
|---|---|
| конструктор по умолчанию `vector()` | чтобы можно было объявить `vector v;` и потом присвоить |
| `explicit vector(int s)` | запрещает неявное `vector v = 10;`, которое создавало бы вектор из 10 элементов случайно |
| `vector(std::initializer_list<double>)` | позволяет писать `vector v = {1.2, 7.89, 12.34};` |
| копирующий конструктор `vector(const vector&)` | при копировании выделяет новую память и копирует элементы — **глубокое копирование** вместо поверхностного |
| копирующее присваивание `operator=(const vector&)` | при `v3 = v1` освобождает старую память, выделяет новую, копирует элементы |
| перемещающий конструктор `vector(vector&&)` | при возврате из функции или `std::move` забирает указатель, не копируя; исходный объект обнуляется |
| перемещающее присваивание `operator=(vector&&)` | то же для `v3 = std::move(v1)` |
| `operator[]` (две версии: для `const` и не `const`) | обычная индексация `v[i]` вместо `get`/`set`; константная версия позволяет читать из `const vector&` |
| `size() const` | остался |

**Ключевые идеи главы 18, отражённые в коде:**
- различие поверхностного и глубокого копирования;
- «пять основных операций» (конструктор, деструктор, копирование, присваивание, конструктор по умолчанию) плюс две операции перемещения — семь операций, которые должны быть продуманы для любого класса, владеющего ресурсом;
- `explicit` для конструктора с одним аргументом;
- `operator[]` должен возвращать ссылку, иначе нельзя писать `v[i] = x;`.

**Внутреннее устройство:** по-прежнему `int sz` и `double* elem`. Ёмкости нет, память выделяется ровно под `sz` элементов.

**Чего ещё нет:**
- изменения размера (`push_back`, `resize`, `reserve`);
- ёмкости `capacity()`;
- проверки выхода за границы (`at()`);
- параметризации типа (`vector<T>`).
